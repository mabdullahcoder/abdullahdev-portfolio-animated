# Project screenshots

Drop one screenshot per project here, named after the project's `id` in `src/data/products.js`.
It replaces that project's mockup automatically (refresh in dev; rebuild for production).

| File            | Project     | Frame   | Best size                     |
| --------------- | ----------- | ------- | ----------------------------- |
| `lumen.png`     | Lumen       | browser | 1600 × 1000 (16:10 landscape) |
| `vault-mail.png`| Vault Mail  | phone   | 1170 × 2532 (phone portrait)  |
| `unify-api.png` | Unify API   | browser | 1600 × 1000                   |
| `taskpilot.png` | Taskpilot   | browser | 1600 × 1000                   |
| `polychat.png`  | Polychat    | browser | 1600 × 1000                   |
| `morph.png`     | Morph       | phone   | 1170 × 2532                   |
| `signchain.png` | SignChain   | browser | 1600 × 1000                   |
| `localmind.png` | LocalMind   | browser | 1600 × 1000                   |

- `.png`, `.jpg`, `.webp` and `.avif` all work; images are optimized automatically.
- Screenshots are anchored to the **top** and cropped at the bottom, so keep the important UI near the top.
- Capture just the app content — the browser window or phone around it is drawn for you.
- To change a frame, edit the project's `shot` field: `"browser"`, `"phone"` or `"full"`
  (`full` fills the whole panel — use it for a designed promo image).
